# 期間限定プロファイル コピー後修正手順

`Reload_Ranked` など既存プロファイルをコピーして `期間限定/<新プロファイル名>` を作ったあと、最低限ここを直せば独立して動く。

## 対象ファイル

- `期間限定/<新プロファイル名>/config.py`
- `期間限定/<新プロファイル名>/pipeline.py`

## 1. config.py で直す項目

### 必須

- `PROFILE_NAME`
  - 例: `PROFILE_NAME = "Reload_Comp_20260326"`

- `OUTPUT_BASE_DIR`
  - 期間限定は共有画像を `shared/images/期間限定/<PROFILE_NAME>` に出す
  - 例:
    - `OUTPUT_BASE_DIR = str(PROJECT_ROOT / "shared" / "images" / "期間限定" / PROFILE_NAME)`

- `PATH_LOOTDATA_DIR`
  - 期間限定の戦利品データは `戦利品データ/期間限定/<PROFILE_NAME>` に出す
  - 例:
    - `PATH_LOOTDATA_DIR = str(PROJECT_ROOT / "戦利品データ" / "期間限定" / PROFILE_NAME)`

- `PATH_HOTFIX_LP`
- `PATH_HOTFIX_LT`
  - `LootPackage.py` / `LootTier.py` はプロジェクトルート側を参照する
  - 例:
    - `PATH_HOTFIX_LP = str(PROJECT_ROOT / "LootPackage.py")`
    - `PATH_HOTFIX_LT = str(PROJECT_ROOT / "LootTier.py")`

- `CACHE_DIR`
- `ICON_CACHE_DIR`
- `RARITY_CACHE_FILE`
- `ASSET_LOC_CACHE_FILE`
- `ICON_CACHE_FILE`
- `RARITY_BG_DIR`
- `RARITY_ICON_DIR`
- `AMMO_ICON_DIR`
- `STAT_TEMPLATE_PATH`
  - 共有キャッシュ/共有アセットは `PROJECT_ROOT / "shared"` 基準にする
  - `COMMON_DIR / "shared"` のままだと `System Update/shared` を見に行ってズレることがある

### Hotfix 入力

- `HOTFIX_LP_PATHS`
- `HOTFIX_LP_TARGETS`
- `HOTFIX_LT_PATHS`
- `HOTFIX_LT_TARGETS`
  - ここはイベントごとに毎回確認する
  - 元のプロファイルのパスが残っていると、別イベントの JSON を生成してしまう

## 2. pipeline.py で直す項目

### 必須

- `PROJECT_ROOT` を追加
  - 例:
    - `PROJECT_ROOT = COMMON_DIR.parent`
    - `if str(PROJECT_ROOT) not in sys.path: sys.path.append(str(PROJECT_ROOT))`

- `WEB_LOOTPOOL_OUT`
  - Web 出力名を新プロファイル名に合わせる
  - 例:
    - `WEB_LOOTPOOL_OUT = r"E:/フォートナイト/Web/loot/data/Reload_Comp_20260326_LootPool.json"`

- `os.environ["SYSTEM_PROFILE"]`
  - コピー元名のままにしない
  - 例:
    - `os.environ["SYSTEM_PROFILE"] = "Reload_Comp_20260326"`

- ロガー名
  - 例:
    - `logging.getLogger("pipeline_Reload_Comp_20260326")`

- 開始/終了ログ文言
  - 例:
    - `===== Reload_Comp_20260326: pipeline start =====`
    - `===== Reload_Comp_20260326: pipeline end =====`

- Git コミット文言
  - 例:
    - `msg = f"Reload_Comp_20260326 update ..."`

## 3. コピー元に残りやすいミス

- `PROFILE_NAME` がコピー元のまま
- `SYSTEM_PROFILE` がコピー元のまま
- Web 出力 JSON 名がコピー元のまま
- `PATH_LOOTDATA_DIR` が `戦利品データ/<コピー元>` のまま
- 画像出力先が `shared/images/<コピー元>` のまま
- `PATH_HOTFIX_LP` / `PATH_HOTFIX_LT` が `COMMON_DIR` 基準のまま
- `HOTFIX_*_PATHS` が別イベント用のまま

## 4. 修正後の確認

### 文字列確認

コピー元名が残っていないか確認する。

```powershell
rg -n "Reload_Ranked|BetterFishing|HazelnutSpread|ItemCache" "期間限定/<新プロファイル名>"
```

### 構文確認

```powershell
python -m py_compile "期間限定/<新プロファイル名>/config.py"
python -m py_compile "期間限定/<新プロファイル名>/pipeline.py"
```

## 5. 期間限定で使うときの基本形

`config.py` は他の期間限定フォルダと同じく、以下の形に寄せると安全。

```python
BASE_DIR = Path(__file__).resolve().parent
COMMON_DIR = BASE_DIR.parent
PROJECT_ROOT = COMMON_DIR.parent

OUTPUT_BASE_DIR = str(PROJECT_ROOT / "shared" / "images" / "期間限定" / PROFILE_NAME)
PATH_LOOTDATA_DIR = str(PROJECT_ROOT / "戦利品データ" / "期間限定" / PROFILE_NAME)
PATH_HOTFIX_LP = str(PROJECT_ROOT / "LootPackage.py")
PATH_HOTFIX_LT = str(PROJECT_ROOT / "LootTier.py")
```

`pipeline.py` は以下の形に寄せると安全。

```python
BASE_DIR = Path(__file__).resolve().parent
COMMON_DIR = BASE_DIR.parent
PROJECT_ROOT = COMMON_DIR.parent

if str(PROJECT_ROOT) not in sys.path:
    sys.path.append(str(PROJECT_ROOT))

os.environ["SYSTEM_PROFILE"] = "<新プロファイル名>"
WEB_LOOTPOOL_OUT = r"E:/フォートナイト/Web/loot/data/<新プロファイル名>_LootPool.json"
```

## 6. Codex に依頼するときの短い頼み方

以下で十分通る。

`期間限定に <新プロファイル名> を作った。コピー元は <元プロファイル名>。正しく動くように修正して`

必要なら追加でこれも書く。

- `Hotfix の参照先も見て`
- `Web 出力名も新プロファイル名にして`
- `期間限定の shared/images と 戦利品データ 配下に分けて`
